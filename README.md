# פרמיירה

מדריך בעברית לסדרות טלוויזיה: קיר פוסטרים מהמדורגת ביותר ומטה, עמוד לכל סדרה, רשימה אישית של סדרות לראות, ולוח השידורים של היום.
פרויקט הגמר שלי בקורס פיתוח ויישום פרונט-אנד (2883) במכללת אונו. נבנה ב-React, ‏TypeScript, ‏Vite ו-React Router, עם בדיקות ב-Vitest.
מה האפליקציה צריכה לעשות כתוב ב-`PRD.md`, וסדר העבודה ב-`tasks.md`.

## תיעוד תהליך העבודה

- [סיכום תהליך העבודה](DEVELOPMENT_LOG.md): שלבי הפיתוח והבדיקות שביצעתי.
- [יומן הפרומפטים המקורי](PROMPTS.md): תיעוד העבודה עם Claude Code.

## העמודים

| כתובת | מה יש בה |
|---|---|
| `/` | קיר הפוסטרים, עם חיפוש לפי שם וסינון לפי ז'אנר. שניהם נשמרים בכתובת, למשל `/?genre=Comedy&q=new`. |
| `/shows/:id` | עמוד של סדרה, למשל `/shows/2`: דירוג, מתי ואיפה שודרה, ז'אנרים, תקציר, שחקנים, ושמירה לרשימה. |
| `/my-list` | הסדרות ששמרתי. הן נשארות גם אחרי רענון. |
| `/today` | לוח השידורים של היום בארה"ב, לפי שעה. |
| כל כתובת אחרת | "העמוד הזה לא בתוכנית", וקישור חזרה לקיר. |

## הרצה

צריך Node בגרסה 22.22 ומעלה, כי React Router 8 דורש אותה. בודקים עם `node -v`.

```bash
npm install
npm run dev
```

ואז פותחים את הכתובת שמופיעה בטרמינל, בדרך כלל http://localhost:5173.

## מאיפה המידע

הכול מ-[TVmaze API](https://www.tvmaze.com/api), בלי מפתח. הכתובות נמצאות ב-`src/api/tvmaze.ts`:

- `https://api.tvmaze.com/shows`: הקיר. זה העמוד הראשון בקטלוג, בערך 240 סדרות, והחיפוש עובר רק עליהן.
- `https://api.tvmaze.com/shows/:id?embed=cast`: עמוד של סדרה, יחד עם השחקנים.
- `https://api.tvmaze.com/schedule?country=US`: לוח השידורים של היום. השעות לפי שעון הרשת בארה"ב.

"הרשימה שלי" נשמרת בדפדפן, ב-`localStorage`, תחת המפתח `premiere:my-list`.

## איך הסדרה שבחרתי מגיעה לעמוד הפרטים

כל כרטיס בקיר הוא `<Link>` לכתובת של הסדרה, למשל `/shows/2` (ב-`ShowCard.tsx`), ולכן לחיצה עליו משנה את הכתובת בלי לטעון את הדף מחדש.
ב-`App.tsx` הנתיב `shows/:id` מחובר לעמוד `ShowPage`, ו-React Router מציג אותו במקום ה-`<Outlet />` שב-`Layout`.
הסדרה שנבחרה לא נשמרת ב-`useState`: היא נשמרת בכתובת, ו-`ShowPage` קורא את המזהה שלה עם `useParams()`.
עם המזהה, `ShowPage` טוען את הסדרה דרך `useFetch` מהכתובת `/shows/2?embed=cast`, והתשובה נשמרת ב-state של ה-hook.
כשהתשובה מגיעה, `ShowPage` מעביר אותה ב-props לרכיב `ShowDetail`, וכיוון שהכול מתחיל מהכתובת, אותו עמוד מופיע גם בכניסה ישירה לקישור וגם אחרי רענון.
